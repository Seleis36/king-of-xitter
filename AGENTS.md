# Agent guide

Before planning cross-track work or choosing the next task, read
[`docs/dependency-graph.md`](docs/dependency-graph.md). Update its Mermaid graph
when work is verified: color a task green only after its implementation passes
the applicable checks, including requirements in ROADMAP §7, and is committed
and pushed. Keep the graph aligned with `ROADMAP.md` and the personal guides in
`docs/team/`.
